## The entry

The program writes exactly one letter to the output file: A. No word, no
explanation, no punctuation, no trailing newline. One byte, one answer.

A names coffee. Coffee is the louder side of the argument: dark, bitter,
steaming, the morning ritual, the jolt. The tasting judge's brief weighs
vividness first after validity, then wit, then truth — and coffee is the
drink that carries the fuller, more alive answer on all three.

## How it works

The entry point is main.py at the repository root. It writes the single
letter A to the output file using plain Python with no dependencies and
no network access. The letter is held in one named constant so the choice
is readable in the code and the output is exactly one byte every run.
